# despensa-lite

Monorepo de aprendizaje: API REST en Node + Express + TypeScript y front en Angular.

```
despensa-lite/
├── api/   # Node + Express + TypeScript (REST de productos, en memoria)
└── web/   # Angular (standalone components)
```

## Requisitos

- Node.js 24 LTS (ver `.nvmrc`). Con nvm-windows: `nvm install 24 && nvm use 24`
- npm (incluido con Node)
